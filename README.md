# Drone

This is a one shared repository for four separate ones I've been working on previously. It consists of Electronic Soeed Controller (ESC), Flight Controller Unit (FCU), Power Distribution Board (PDB), and Remote Controller (RC) hardware projects. The initial idea was supposed to use these four to make a working flying drone. Currently they only show what I've been doing when I first started PCB journey with some of design choices and my very limited knowledge and skillset back then. And at this time none of them is being worked on anymore.
